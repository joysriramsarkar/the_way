# দ্য ওয়ে (The Way) — আন্তর্জাতিক সমাজতান্ত্রিক চিন্তন ও গণআন্দোলনের উন্মুক্ত পোর্টাল
### Voice of International Socialism & Global Working-Class Solidarity

> *“জগতের সকল শোষিত মানুষ এক হও!”*  
> *“Workers & Oppressed Peoples of All Lands, Unite!”*

---

## 🚩 পরিচিতি ও মতাদর্শিক লক্ষ্য (Vision & Mission)

**দ্য ওয়ে (The Way)** হলো একবিংশ শতাব্দীর নব্য-সাম্রাজ্যবাদী ও নব্য-উদারবাদী শোষণের বিরুদ্ধে বিশ্ব মেহনতি জনতার এক বৈপ্লবিক চিন্তন, তাত্ত্বিক গবেষণা ও গণসংগ্রামের বহুভাষিক উন্মুক্ত ডিজিটাল পোর্টাল। 

আধুনিক **Next.js 16 (App Router)** ও **TypeScript** প্রযুক্তিতে নির্মিত এই প্ল্যাটফর্মটি আন্তর্জাতিক সংহতি, মার্ক্সীয়-লেনিনীয় ক্লাসিক্স লাইব্রেরি, রাজনৈতিক-অর্থনৈতিক গবেষণা এবং মেহনতি মানুষের বিকল্প সংহতি নেটওয়ার্ক হিসেবে পরিচালিত।

- **🌐 লাইভ প্রোডাকশন পোর্টাল**: [https://thewaysocialist.vercel.app/](https://thewaysocialist.vercel.app/)

## ✨ প্রধান বৈশিষ্ট্যসমূহ (Core Features)

### ১. সর্বজনীন বহুভাষিক প্ল্যাটফর্ম (11-Language i18n Architecture)
পোর্টালটিতে বর্তমানে বিশ্বব্যাপী **১১টি আন্তর্জাতিক ভাষা** সম্পূর্ণ সক্রিয়:
- 🇧🇩 **বাংলা (bn)**
- 🇬🇧 **English (en)**
- 🇮🇳 **हिन्दी (hi)**
- 🇪🇸 **Español (es)**
- 🇸🇦 **العربية (ar)** *(স্বয়ংক্রিয় RTL লেআউটসহ)*
- 🇨🇳 **中文 (zh)**
- 🇷🇺 **Русский (ru)**
- 🇫🇷 **Français (fr)**
- 🇧🇷 **Português (pt)**
- 🇯🇵 **日本語 (ja)**
- 🇰🇷 **한국어 (ko)**

*বৈশিষ্ট্য*: ইনস্ট্যান্ট সিঙ্ক্রোনাস ডিকশনারি (`lib/translationsData.ts`) এবং ডায়নামিক লোকাল ফলব্যাক (`public/locales/*.json`) নিশ্চিত করে যে গ্লোবাল স্ট্যাটস বার, অ্যাকশন সেন্টার, দৈনিক বিপ্লবী উক্তি, কমরেডস ও পাঠচক্র তালিকা এবং মেহনতি মানুষের বুলেটিন প্রতিটি ভাষায় তাৎক্ষণিকভাবে অনূদিত হয়।

### ২. বিপ্লবী উন্মুক্ত পাঠাগার ও ক্লাসিক্স রিডার (Revolutionary Classics Library)
- **কার্ল মার্ক্স ও ফ্রিডরিখ এঙ্গেলস**: *কমিউনিস্ট পার্টির ইশতেহার, পুঁজি (১ম খণ্ড), পরিবার, ব্যক্তিগত মালিকানা ও রাষ্ট্রের উৎপত্তি*।
- **ভ্লাদিমির লেনিন**: *রাষ্ট্র ও বিপ্লব, সাম্রাজ্যবাদ: পুঁজিবাদের সর্বোচ্চ পর্যায়*।
- **জোসেফ স্ট্যালিন**: *Problems of Leninism, দ্বান্দ্বিক ও ঐতিহাসিক বস্তুবাদ*।
- **মাও সেতুং**: *বাস্তব অনুশীলন প্রসঙ্গে (On Practice), দ্বন্দ্ব প্রসঙ্গে (On Contradiction)*।
- **ম্যাক্সিম গোর্কি**: *মা (Mother)*।
- **শহীদ ভগৎ সিংহ**: *কেন আমি নাস্তিক (Why I am an Atheist)*।
- **কোরীয় সমাজতান্ত্রিক সাহিত্য (North Korean & Juche Literature)**: *অন দ্য জুচে আইডিয়া, সমাজতান্ত্রিক সংস্কৃতির বিকাশ ও সাম্রাজ্যবাদবিরোধী সংগ্রাম বিষয়ক ক্লাসিক্স*।
- **স্মার্ট রিডার ইঞ্জিন (`/books/[id]`)**: অধ্যায়ভিত্তিক রিডিং, রেস্পন্সিভ ন্যাভিগেশন, ৪টি পড়ার থিম (Light, Dark, Sepia, Crimson), ফন্ট সাইজ কন্ট্রোলার এবং রিয়েল শব্দের সংখ্যার ভিত্তিতে নিখুঁত পড়ার সময় (reading time) গণনা।

### ৩. ইন্টিগ্রেটেড লাইভ সার্চ ইঞ্জিন (Unified Search Engine)
- `/api/search` এপিআই-এর মাধ্যমে লোকাল সমাজতান্ত্রিক গ্রন্থাগারের শত শত ক্লাসিক্স এবং উন্মুক্ত প্রবন্ধসমূহের রিয়েল-টাইম সার্চ।
- লোকাল লাইব্রেরির ফলাফলকে সর্বোচ্চ অগ্রাধিকার দিয়ে তাৎক্ষণিক রেজাল্ট প্রদর্শন।

### ৪. মেহনতি মানুষের আন্তর্জাতিক নেটওয়ার্ক (Solidarity Network Hub)
- **কমরেডস ও চিন্তাবিদ ডিরেক্টরি (`/directory`)**: গবেষক, লেখক ও সংগঠকদের সমন্বিত তালিকা।
- **সমাজতান্ত্রিক পাঠচক্র ও সেল (`/groups`)**: মার্ক্স, লেনিন, গ্রামশি ও ফ্যাননের চিন্তাভিত্তিক স্থানীয় ও ডিজিটাল স্টাডি সার্কেল।
- **আন্তর্জাতিক সংহতি ইভেন্টস ও ওয়্যার (`/events`, `/feed`)**: বিশ্বজুড়ে শ্রমিক আন্দোলন ও সাম্রাজ্যবাদবিরোধী লড়াইয়ের লাইভ আপডেট।
- **লেখা ও গবেষণা জমাদান (`/submit`)**: লেখক ও কর্মীদের রাজনৈতিক-অর্থনৈতিক বিশ্লেষণ প্রকাশের প্ল্যাটফর্ম।

### ৫. প্রডাকশন-রেডি স্থাপত্য ও জিরো মক ডেটা (Zero Mock Architecture)
- সম্পূর্ণ মক ডেটামুক্ত রিয়েল স্টোরেজ ও এপিআই ব্যবস্থা।
- PostgreSQL / Neon Serverless ডাটাবেজ ইন্টিগ্রেশন এবং স্থিতিস্থাপক লোকাল ব্যাকআপ।
- কঠোর টাইপ-সেফটি (Strict TypeScript 5.7+)।

## 🚀 লোকাল সেটআপ ও রান (Getting Started)

### ১. ডিপেন্ডেন্সি ইনস্টল করুন
```bash
npm install
```

### ২. টাইপস্ক্রিপ্ট ভ্যালিডেশন
```bash
npm run type-check
```

### ৩. লোকাল ডেভেলপমেন্ট সার্ভার চালু করুন
```bash
npm run dev
```

ব্রাউজারে ভিজিট করুন: **`http://localhost:3000`**

### ৪. প্রোডাকশন বিল্ড তৈরি করুন
```bash
npm run build
npm start
```

## 🌐 ভাষা নির্বাচন ও আন্তর্জাতিকীকরণ (i18n)

যেকোনো নতুন ট্রান্সলেশন কি যোগ করতে:
1. `lib/translationsData.ts`-এ স্ব স্ব ভাষার অবজেক্টে কি (Key) ও অনুবাদ মান যুক্ত করুন।
2. `public/locales/[lang].json`-এ কি সিঙ্ক করুন।
